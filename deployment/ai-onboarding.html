新手入门 · MCP 与 Skill

让你常用的 AI，也能查量化天成

你可以直接在官网使用知库；也可以把研究检索、课程目录等功能，连接到自己信任的 AI 助手。先看懂下面两个概念，再决定怎么用。

MCP · 负责连接
MCP 是什么？给 AI 接上工具

MCP 是让 AI 软件连接外部工具的一种通用方式。可以把它理解为一条接到知库的“连接线”。

连接量化天成后，AI 可以按你的提问调用研究搜索、回查原文入口、查询课程目录。它能查什么，仍由你的官网账号权限决定。

Skill · 提供方法
Skill 是什么？给 AI 一份做事指南

Skill 是一套可安装的操作说明和配套资料，告诉 AI 什么时候做什么、先后顺序是什么，以及结果该怎样呈现。

量化天成研究 Skill 会引导 AI 先确认权限，再搜索资料、核对来源，最后说明日期和资料缺口。它也附有辅助调用脚本。

两者怎样配合？看一个例子
“帮我搜索人工智能产业链的研究，列出资料来源和明确日期，再整理还需要核实的问题。”
  1. 你提出研究问题
  2. Skill 指引查证步骤
  3. MCP 连接官网取资料
  4. AI 整理并列出来源

上面是提问示例。实际内容以检索结果为准；检索片段不等于全文，PDF 会提供官网原件入口，日期缺失会如实说明。

第一次用，从这里选
连接我的 AI 助手下载研究 Skill（可选）

连接自己的 AI：登录官网 → 领取个人密钥 → 在 AI 客户端填写连接信息 → 提一个问题试用。连接页会带你完成每一步。

必须同时安装 MCP 和 Skill 吗？

先连接 MCP，就能使用已开放的工具。Skill 是可选的研究指南，帮助 AI 按步骤查证；下载或安装 Skill 不等于已连接官网，也不会自动开通会员。使用本套 Skill 访问官网，同样需要服务地址和个人密钥。

我的 AI 软件能用吗？还要另外付费吗？

软件需要支持远程 MCP 和自定义 Authorization 请求头；使用 Skill 还需要支持技能文件。不同软件的设置方式不同，首版尚不支持 OAuth 一键登录。使用量化天成研究仍需相应会员权限，独立付费课程仍需另购；AI 软件或模型的费用按各自规则计算。

首版提供研究检索、原文文本或原件入口、课程目录与复盘入口；不提供实时行情、复盘数值、视频下载或交易功能。请只把个人密钥填入你信任的客户端。
